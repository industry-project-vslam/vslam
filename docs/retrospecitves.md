# Retrospective

## Week 01

### Summary

During the first week we got a more detailed explenation of the project from our client. We focussed mainly on literature research and testing sample code for all technologies our end result might use.

### Positives

During the kickoff presentation all team members contributed to getting a clearer view of our clients demands by asking the right questions. This resulted in a good understanding of our goals and the work needed to accomplish those. Each member had their own area to work on. Everyone was very driven for literature research, checking out existing repositories and initial example code testing. Results followed fast, development went smooth. There was a good team vibe. The progress of week one resulted in image based pointcloud maps, P2P drone communication, image streaming with the AI deck.

### Negatives

The quick start did have some drawbacks. Because everyone was very focussed on their individual work, integration and agile principles were neglected. There was no improvement of the project board, backlog and it wasn't updated when working on tasks. This resulted in repetition of tasks. Not all tests and research was added to the github code base. Early good results also prevented looking further into more existing implementations. Systems all work seperate but no systems had been combined yet.
