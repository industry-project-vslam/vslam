# Citation template
To be put into **CITATIONS.BIB**

```
@article{citekey,
  author    = {Last, First and Last2, First2},
  title     = {Your Title Here},
  journal   = {Journal Name},
  volume    = {11},
  number    = {1},
  pages     = {24},
  year      = {2022},
  doi       = {10.xxxx/xxxxx},
  url       = {https://...}
}
```

**e.g.**

```
@article{carrel2022visualslam,
  author    = {Carrel, Frédérick},
  title     = {A Comprehensive Survey of Visual {SLAM} Algorithms},
  journal   = {Robotics},
  volume    = {11},
  number    = {1},
  pages     = {24},
  year      = {2022},
  month     = {feb},
  publisher = {Multidisciplinary Digital Publishing Institute},
  doi       = {10.3390/robotics11010024},
  url       = {https://www.mdpi.com/2218-6581/11/1/24},
  issn      = {2218-6581}
}
```
