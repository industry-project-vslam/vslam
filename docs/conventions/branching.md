# dev
- Is the root branch
- When making branch: in **dev** do `git checkout -b <section>/<feature>` e.g. `git checkout -b docs/conventions`

# Sections
- **research**
- **docs**
- **material**
- **code**
- **testing**
- **management**

# Merge sequence
- Merge **dev** to `<section>/<feature>`
- Solve conflicts on `<section>/<feature>`
- merge solved `<section>/<feature>` to **dev**
