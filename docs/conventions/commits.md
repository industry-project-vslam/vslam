# Commit sequence
- On `<section>/<feature>`
  - `git add <objects>`
  - `git commit -m "<verb>: <message>"`
  - `git push`

# Commit verbs

- **feat** — new file, feature, dependency, test
- **fix** — bug fix, crash, incorrect behavior
- **refactor** — restructure code without changing behavior
- **move** — relocate file or code to different place
- **clean** — remove dead code, unused imports, lint fixes
- **revert** — undo a previous commit
- **merge** — merge branch into another
- **build** — comments, docstrings, README changes
- **test** — add or update tests
