# GitHub Scrum: Issue → Branch → PR flow

## Create an issue
- Go to **Issues** → **New issue**
- Set a **title**, **Assignees**, **Labels**, **Type**, **Project**, **Milestone**
- **Create**

## Manage issue in scrum
- Drag the issue card from **Backlog** → **In Progress** on the project board or to any other section
- Mark it as done on merge
