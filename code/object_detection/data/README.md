# Data

`data/labeled/` is the committed source dataset used by the training notebooks.
It is included so another laptop can train and run benchmark checks from the
repository.

Use these paths when training:

```text
data/labeled/human_detection/
data/labeled/posture_classification/
data/processed/
```

`data/labeled/` contains downloaded or manually prepared datasets.
`data/processed/` contains splits generated by notebooks and is ignored by Git.
